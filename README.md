Welcome to JS Playground! 🎉

This repository is a personal collection of all my JavaScript practice, experiments, and projects from my learning journey. From the basics to advanced concepts, everything I learned and tried is included here.

📂 What’s Inside

Core JavaScript Concepts – variables, functions, loops, objects, arrays, destructuring, spread, etc.

DOM Manipulation & Events – working with HTML, CSS, and JS together.

Advanced JS – arrow functions, async/await, modules, promises, etc.

Practice Exercises – small scripts and exercises to reinforce concepts.

Projects & Demos – Firebase CRUD apps, Supabase tutorials, and other mini projects.

Learning Notes – snippets and code experiments as I explored JS features.

💡 Purpose

The goal of this repository is to document my journey learning JavaScript, provide a reference for myself in the future, and help others who are exploring JS to see practical examples.

🚀 How to Use

Clone the repo:

git clone https://github.com/hussainshamim16/js-playground.git


Explore folders and files.

Open HTML files in your browser to see projects and demos.

Review JS files for practice examples and notes.
